REFLECTION ON AI USAGE
================================================================================

Throughout this project, AI (Claude) was used primarily as a learning tool and
reference guide rather than for direct code generation. The prompts show a
progression from basic setup questions to more advanced architectural decisions.

Key areas where AI helped with learning:
- Understanding Foundry framework vs other tools like Hardhat
- Learning Solidity security patterns (reentrancy, access control, pull payments)
- Debugging test failures and understanding Foundry testing syntax
- Grasping smart contract design patterns and best practices
- Learning command-line tools (forge, cast, anvil)

The human developer clearly:
- Wrote the actual code themselves (evidenced by debugging questions)
- Made architectural decisions (questions compare options, ask for pros/cons)
- Tested and iterated (many questions about fixing errors they encountered)
- Researched and asked follow-up questions showing deeper understanding
- Applied knowledge across different parts of the project

AI was used as a teaching assistant and documentation resource, not as a code
generator. The questions show genuine learning and problem-solving rather than
requesting completed solutions.
